// 01

Summary

Sequel is the second machine of HackTheBox Starting Point Tier 1. It targets a MariaDB (MySQL-compatible) database server that is accessible from the network with the root account having no password set. This is a direct parallel to the Meow machine's Telnet misconfiguration, but applied to a database service.

MariaDB listens on port 3306 by default. When configured without a root password and bound to a network interface (rather than localhost), any client can connect with full administrative privileges and read, modify, or delete any database on the server.

The attack chain: connect with mysql -h target -u root, enumerate databases with SHOW DATABASES, switch to the htb database, list tables, and dump the config table to find the flag.

# Vulnerability Technique Impact
1 MySQL/MariaDB root with no password Direct mysql client connection Full DBA access to all databases

// Key takeaway

MySQL/MariaDB must always have a strong root password. The mysql_secure_installation script exists specifically to enforce this during setup. Database services should also be bound to 127.0.0.1 and never directly exposed to the network unless explicitly required — and even then, always behind authentication.

Reconnaissance

Nmap scan

PORT STATE SERVICE VERSION
3306/tcp open mysql MariaDB (unauthorized)
|_mysql-info: Host '10.10.x.x' is not allowed to connect to this MariaDB server

Port 3306/tcp is open running MariaDB. The Nmap output shows "unauthorized" — but this refers to Nmap's script being blocked, not the root user. We must try connecting directly with the mysql client to confirm access.

Tool Reference

mysql (client)
mysql -h <host> -u <user> [-p]
MySQL/MariaDB command-line client for interactive database sessions.
  • -h — remote host
  • -u — username
  • -p — prompt for password
  • SHOW DATABASES; — list all DBs
  • USE <db>; — select database
  • SHOW TABLES; — list tables
  • SELECT * FROM <table>; — dump table
mysql_secure_installation
sudo mysql_secure_installation
Post-installation hardening script that sets a root password, removes anonymous users, and restricts remote root login.
  • Sets root password
  • Removes anonymous users
  • Disables remote root login
  • Removes test database

// 06

Glossary

MySQL / MariaDB
MySQL is the world's most widely used open-source relational database management system, using SQL. MariaDB is a community-maintained fork created after Oracle acquired MySQL. Both use port 3306 by default and share the same client tools and protocol. They organize data into databases → tables → rows/columns. The root superuser account has unrestricted access to all databases and system operations. A root account without a password on a network-accessible MySQL instance is equivalent to a root shell — an attacker has complete control over all data.
Database Enumeration Workflow
When accessing a database without a specific target, the standard enumeration workflow is: (1) SHOW DATABASES; — list all databases, (2) USE <db>; — select an interesting one, (3) SHOW TABLES; — list its tables, (4) DESCRIBE <table>; — view column structure, (5) SELECT * FROM <table> LIMIT 10; — sample the data. This methodical approach quickly surfaces sensitive data like credentials, API keys, and in CTFs, flags.
